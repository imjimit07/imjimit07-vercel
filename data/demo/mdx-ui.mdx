Everything on this page renders from a single MDX file through the shared
component mapping — content files never import UI components.

## Callouts

<Callout type='info' title='Before you begin'>
  Ensure the MDX component mapping includes every element your content uses.
</Callout>

<Callout type='success'>
  Registered components render anywhere in the document.
</Callout>

<Callout type='warning'>
  Copy buttons need a secure context — `https` or `localhost`.
</Callout>

<Callout type='danger'>
  Never put business logic in MDX; push it into a reusable component.
</Callout>

## Code

Fenced blocks get syntax highlighting, a copy button, and optional title bars
through the `lang:title` meta:

```tsx:components/mdx/Badge.tsx
const variants = {
  default: 'bg-gray-900 text-white',
  outline: 'ring-1 ring-gray-300',
};

export default function Badge({ variant = 'default', children }) {
  return <span className={variants[variant]}>{children}</span>;
}
```

## Links & inline code

External links are handled safely — see [MDX](https://mdxjs.com) and
[Next.js](https://nextjs.org) — while inline code like `npm run build` keeps
its own treatment.

> Blockquotes keep the prose treatment; use them for pull quotes.

### A heading to test anchor links

Hover a heading and a `#` appears; jumping to it respects the sticky header.
